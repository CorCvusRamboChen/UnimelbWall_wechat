# Unimelb Wall WeChat Design System

## Product direction

墨大墙微信小程序是校园社区的只读公开帖子镜像，不是营销页，也不是完整社交客户端。界面优先保证内容可信、浏览高效、同步状态透明，并与母项目保持明确的品牌连续性。

设计依据：

- 母项目当前 UniMelb tenant 的品牌色与信息流结构。
- `ui-ux-pro-max` 的 Minimalism / Swiss Style、移动触控、安全区、加载反馈和可访问性建议。
- 原生微信小程序 WXML/WXSS 的能力边界；不引入 Web 字体、GSAP 或第三方 UI 框架。

## Visual language

- 风格：克制的校园编辑风格，内容优先，轻量、清晰、可信。
- 品牌锚点：深海军蓝顶部区域、方形“墨”字标、白色内容面。
- 信息流：沿用母项目“单列帖子流 + 清晰分隔线”的结构，不使用过度悬浮的大圆角卡片。
- 匿名内容：使用中性灰头像和轻微灰色背景；不能只靠颜色，必须显示“匿名”文字。
- 动效：只保留按压反馈与骨架屏；不做入场编排、视差或自动轮播。

| Brand bright | `#0A4DB3` | 链接、选中态、认证信息 |
| Brand weak | `#E8EEF8` | 选中分类、品牌弱背景 |
| Canvas | `#F5F7FB` | 页面背景 |
| Surface | `#FFFFFF` | 帖子、信息与状态面板 |
| Surface muted | `#F0F2F6` | 骨架、匿名内容、次级区域 |
| Line | `#E4E8EF` | 边框和分隔线 |
| Text | `#20242C` | 标题和正文 |
| Muted | `#687082` | 辅助信息；在白底上保持可读对比 |

颜色不单独承担语义；置顶、匿名、视频和同步异常均配有明确文字。

## Typography

- 字体：微信系统字体栈；不加载远程字体。
- 品牌字标：系统衬线字体，仅用于“墨”字标和品牌名。
- 页面标题：40–44rpx，700。
- 帖子标题：32–36rpx，700，行高 1.4。
- 正文：28–30rpx，行高 1.7–1.8。
- 辅助信息：23–25rpx；正文信息不得小于 24rpx。
- 长正文保持自然换行，允许长 URL 和连续字符断行。

## Spacing and shape

- 基础节奏：8rpx；主要间距使用 16 / 24 / 32 / 48rpx。
- 页面水平边距：手机 24rpx；大屏最大内容宽度 1120rpx。
- 控件圆角：8rpx；内容面板 12–16rpx；胶囊仅用于短状态标签。
- 触控目标：按钮至少 88rpx 高宽，邻接控件至少 16rpx 间距。
- 阴影仅用于需要从背景抬升的品牌栏；帖子主要依靠边框和留白分层。

## Core components

### Brand header

- 左侧为 72rpx 方形“墨”字标和中英文品牌名。
- 右侧“关于”为带文字按钮，避免无标签图标。
- 深海军蓝纯色背景，不使用渐变或玻璃效果。

### Mirror status

- 明确写出“公开帖子只读镜像”。
- 展示最近同步时间；异常状态使用带说明文字的警告面板。

### Category navigation

- 横向滚动，分类按钮保持单行并有足够触控高度。
- 选中状态同时改变背景、边框与字重。

### Post row

- 作者首字头像、作者/匿名状态、分类和发布时间构成第一层。
- 标题和摘要为主要阅读层；媒体预览位于正文之后。
- 置顶、匿名、视频标签只在对应状态出现。
- 整行可点击，必须有语义化可访问标签和稳定的按压反馈。

### Detail article

- 沿用作者行、标签、标题、正文、媒体、只读评论说明的顺序。
- 图片支持预览，视频使用原生控件；混合媒体保持源顺序。
- 长文在大屏保持最大阅读宽度，不全宽铺开。

## Interaction and accessibility

- 所有按钮使用原生 `button` 或原生媒体控件。
- 按压态只改变背景、边框或透明度，不缩放布局。
- 图片懒加载；加载阶段预留稳定空间，避免布局跳动。
- 骨架动画在 reduced-motion 环境关闭。
- 页面底部加入 `env(safe-area-inset-bottom)`。
- 错误、空状态和同步延迟都必须提供文本说明；可重试错误提供按钮。
- 不使用 emoji 作为结构图标，不依赖横向滑动完成唯一操作。

## Anti-patterns

- 紫色社区模板、绿色营销 CTA、儿童化字体。
- 大面积渐变、玻璃拟态、重阴影和过度圆角。
- 用图标替代必要文字、用颜色单独表达状态。
- 将母项目的登录、发帖、点赞、收藏或评论操作伪装成可用功能。
- 为了视觉密度牺牲触控尺寸、正文对比度或长文本换行。

## Validation targets

- 375px 等效小屏、常规大屏手机、平板与横屏。
- 最大系统字体下标签可换行且正文不裁切。
- 所有交互目标满足至少 88rpx 的微信触控区域。
- 浅色模式文字对比度、边框和按压态可辨识。
- 微信开发者工具中验证下拉刷新、分页、图片预览、视频播放及安全区。
